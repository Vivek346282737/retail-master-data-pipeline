# Enterprise Retail Master Data & Governance Analytics Pipeline

Production-ready Master Data Management (MDM) architecture implementing 3NF normalization, automated anomaly detection, deduplication workflows, and business intelligence KPI reporting.

## Highlights
- Normalized Relational Schema (3NF) with integrity constraints.
- Automated Data Cleansing Engine with Python.
- Enterprise SQL Analytics featuring CTEs and Window Functions.
- Master Data Governance Documentation.

## Execution
Run cleaner: python data_cleaner.py
